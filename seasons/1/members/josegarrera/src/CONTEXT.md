# Content Library

## Glossary

- **Content Item** — one piece of community material (a lesson, a recording, a post, …) that lives in the community platform and is listed in the Content Library. Each item links back to where it lives.
- **Content Card** — how the Content Library presents one Content Item: its title, type, excerpt, link and a readable Published date, ready to render.
- **Content Library** — the page that lists Content Items, newest first, optionally narrowed by the Type filter.
- **Content Type** — the open-ended category of a Content Item (`lesson`, `blueprint`, `office-hours`, …). There is no fixed set; it is displayed verbatim.
- **Type filter** — narrows the Content Library to one Content Type at a time, or to every type ("All types"). Its options are whichever Content Types are present in the Data source.
- **Selected type** — the Content Type the visitor last chose in the Type filter, remembered across visits. When it no longer exists in the Data source, the Content Library shows all types.
- **Published date** — the day a Content Item was published in the community platform. Items are ordered by it, newest first.
- **Data source** — the frozen local JSON file every Content Item comes from. It is read-only; the app never edits it and never relies on its order.
